Password reset

Simple recovery, tightly scoped.

This request route is deliberately narrow. It does not create accounts, change roles, or expose internal details. It only starts the recovery path for an existing invited user.

Existing accounts only

Recovery should only operate for already-linked users.

Expiry controlled

Reset tokens need short expiry and clear timestamps.

Audit trace

Reset request should be visible to admins without creating noise for families.

No guesswork

Users need plain language, not vague security theatre.
